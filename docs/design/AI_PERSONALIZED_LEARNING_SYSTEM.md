# AI-Powered Personalized Learning System

## Revolutionary Adaptive CPA/CFO Training

---

## 🎯 THE VISION

**Problem:** Traditional courses force everyone through the same linear path, regardless of their actual job needs.

**Solution:** AI-powered intake that asks users about their:

- Current job role and responsibilities
- Immediate pain points and blockers
- Timeline/urgency (what they need to fix NOW vs. later)
- Learning goals (pass CPA exam, get promoted, fix specific work issue)

**Result:** Custom curriculum that prioritizes the EXACT lessons they need, in the order they need them.

---

## 🧠 HOW IT WORKS

### **Step 1: User Onboarding - AI Conversation**

When a user signs up, they have a conversation with the AI:

```
AI: "Hi! I'm your CPA/CFO learning assistant. Let's build your personalized study plan.

First, what's your current role?"

     • Job Training Mode - Your daily work problems prioritized first

     You can switch between modes or study both simultaneously. Let me build your custom learning path..."
```

```sql
  created_at TIMESTAMP
);

-- Index for vector similarity search
CREATE INDEX idx_note_embeddings_vector ON note_embeddings USING ivfflat(embedding vector_cosine_ops);
```

### **AI Curriculum Generator Algorithm**

```python
def generate_personalized_curriculum(user_profile, pain_points):
    """
    Generate custom learning path based on user profile and pain points
    """
    curriculum = []

    # Step 1: Sort pain points by urgency
    critical = [p for p in pain_points if p.urgency == 'CRITICAL']
    high = [p for p in pain_points if p.urgency == 'HIGH']
    medium = [p for p in pain_points if p.urgency == 'MEDIUM']
    low = [p for p in pain_points if p.urgency == 'LOW']

    # Step 2: Map pain points to lessons
    lesson_mapping = {
        'bank_rec_mess': 'cfo-month1.w1',
        'beginning_balance_issues': 'cfo-month1.w1',
        'prior_year_not_closed': 'cfo-month1.w1',
        'gl_export_all_accounts': 'cfo-month1.w2',
        'mystery_journal_entries': 'cfo-month1.w3',
        'retained_earnings_unclear': 'cfo-month1.w3',
        'multi_line_matching': 'cfo-month1.w4',
        'retainage_setup': 'cfo-month2.w1',
        'wip_schedules': 'cfo-month2.w2',
        'job_costing': 'cfo-month2.w2',
        'progress_billing': 'cfo-month2.w3',
        'intercompany_issues': 'cfo-month2.w4',
        'excel_manual_work': 'cfo-month3.w1',
        'no_close_checklist': 'cfo-month3.w3',
        'cpa_exam_far': 'module5',  # Revenue module
        'cpa_exam_aud': 'module1',  # Consolidations (common AUD topic)
        # ... more mappings
    }

    # Step 3: Build curriculum by urgency
    week_num = 1

    # CRITICAL items (Week 1-N)
    for pain_point in critical:
        lesson_key = lesson_mapping.get(pain_point.specific_issue)
        if lesson_key:
            curriculum.append({
                'week': week_num,
                'module_lesson': lesson_key,
                'priority': 'CRITICAL',
                'reason': f"Fixes: {pain_point.specific_issue}",
                'estimated_hours': 5
            })
            week_num += 1

    # HIGH items
    for pain_point in high:
        lesson_key = lesson_mapping.get(pain_point.specific_issue)
        if lesson_key:
            curriculum.append({
                'week': week_num,
                'module_lesson': lesson_key,
                'priority': 'HIGH',
                'reason': f"Improves: {pain_point.specific_issue}",
                'estimated_hours': 5
            })
            week_num += 1

    # MEDIUM items
    for pain_point in medium:
        lesson_key = lesson_mapping.get(pain_point.specific_issue)
        if lesson_key:
            curriculum.append({
                'week': week_num,
                'module_lesson': lesson_key,
                'priority': 'MEDIUM',
                'reason': f"Strengthens: {pain_point.specific_issue}",
                'estimated_hours': 5
            })
            week_num += 1

    # LOW items (CPA exam prep, etc.)
    for pain_point in low:
        lesson_key = lesson_mapping.get(pain_point.specific_issue)
        if lesson_key:
            curriculum.append({
                'week': week_num,
                'module_lesson': lesson_key,
                'priority': 'LOW',
                'reason': f"Prepares: {pain_point.specific_issue}",
                'estimated_hours': 5
            })
            week_num += 1

    return curriculum
```

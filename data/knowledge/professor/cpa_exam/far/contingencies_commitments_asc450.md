# Contingencies and Commitments - ASC 450

## Overview
Contingencies are existing conditions involving uncertainty that may result in gain or loss. ASC 450 provides guidance on recognition and disclosure.

---

## Loss Contingencies

### Definition
Existing condition involving uncertainty that may result in a **loss**

### Examples
- Lawsuits and litigation
- Product warranties
- Environmental liabilities
- Guarantees
- Pending or threatened litigation

---

## Probability Levels

### Probable
**Likelihood**: > 75% likely to occur

**Accounting**: **ACCRUE and DISCLOSE**

### Reasonably Possible
**Likelihood**: 25-75% likely to occur

**Accounting**: **DISCLOSE only** (do not accrue)

### Remote
**Likelihood**: < 25% likely to occur

**Accounting**: **NO accrual, NO disclosure** (Exception: guarantees always disclosed)

---

## Recognition Criteria for Loss Contingencies

### Accrue if BOTH:
1. **Probable** (likely to occur)
2. **Reasonably estimable** (can estimate amount)

### Journal Entry
```
DR Loss (or Expense)
   CR Liability
```

### Disclosure Only
If **reasonably possible** (but not probable)
- Disclose in notes
- Do **NOT** accrue

### No Action Required
If **remote** (slight chance)
- No accrual
- No disclosure
- **Exception**: Guarantees always disclosed

---

## Measurement of Loss Contingencies

### Single Amount
Use that amount if it's the best estimate

### Range of Estimates

**If one amount in range is more likely**:
- Use that amount

**If no amount is more likely**:
- Use **MINIMUM** amount in range (most conservative)

### Example
Lawsuit estimated loss: $100,000 - $500,000
No amount is more likely than any other

**Accrue**: $100,000 (minimum)
**Disclose**: Range of possible loss ($100K - $500K)

---

## Gain Contingencies

### Accounting Rule
Do **NOT accrue** gains until realized (conservatism principle)

### Disclosure
Disclose if **probable**, but avoid misleading language about likelihood

### Example
Lawsuit in company's favor
- Do **NOT** recognize gain until case settled and cash received
- May disclose potential gain (with caution)

---

## Warranties

### Assurance Warranty
**Definition**: Standard warranty assuring product works as intended

**Accounting**: Accrue under **ASC 450** as loss contingency

**Entry**:
```
DR Warranty Expense
   CR Warranty Liability
```

### Service Warranty (Extended Warranty)
**Definition**: Extended warranty purchased separately (beyond standard)

**Accounting**: Performance obligation under **ASC 606** (revenue recognition)

---

## Commitments

### Definition
Obligation to perform in future (e.g., purchase commitments, employment contracts)

### Accounting
Generally **not recorded** until performance occurs

**Disclosure**: Disclose if material

### Loss on Purchase Commitment
If committed to purchase at price > market:
- **Accrue loss** if probable and estimable

### Example
Committed to purchase inventory for $100,000
Current market value: $80,000
**Accrue loss**: $20,000

```
DR Loss on Purchase Commitment    $20,000
   CR Liability                            $20,000
```

## Detailed Examples

### Example 1: Probable and Estimable Lawsuit

**Facts**:
- Defendant in lawsuit
- Legal counsel advises loss is **probable**
- Estimated loss: $250,000

**Accounting**:
```
DR Loss from Lawsuit             $250,000
   CR Litigation Liability                $250,000
```

**Disclosure**: Describe nature of litigation and amount accrued

---

### Example 2: Reasonably Possible Lawsuit

**Facts**:
- Defendant in lawsuit
- Legal counsel advises loss is **reasonably possible** (not probable)
- Estimated loss: $100,000 - $300,000

**Accounting**: **NO accrual**

**Disclosure**: Disclose in notes:
- Nature of contingency
- Estimate of possible loss or range

---

### Example 3: Range with No Best Estimate

**Facts**:
- Environmental remediation required
- Loss is **probable**
- Estimated cost: $500,000 - $800,000
- No amount in range is more likely

**Accounting**:
```
DR Environmental Remediation Loss   $500,000
   CR Environmental Liability                $500,000
```
(Use **minimum** of range)

**Disclosure**: Range of possible loss ($500K - $800K)

---

### Example 4: Warranty

**Facts**:
- Sold products with 1-year warranty
- Estimated warranty costs: 2% of sales
- Sales: $1,000,000

**Accounting**:
```
DR Warranty Expense               $20,000
   CR Warranty Liability                   $20,000
```
($1,000,000 × 2%)

## CPA Exam Decision Framework

```
Is loss probable (>75%)?
  ├─ NO → Is it reasonably possible (25-75%)?
  │         ├─ YES → DISCLOSE only
  │         └─ NO (remote) → No action (except guarantees)
  │
  └─ YES (probable) → Can amount be reasonably estimated?
                ├─ YES → ACCRUE and DISCLOSE
                └─ NO → DISCLOSE only
```

---

## CPA Exam Tips

1. **Probable + Estimable** = **ACCRUE**

2. **Reasonably possible** = **DISCLOSE only**

3. **Remote** = **Nothing** (except guarantees - always disclose)

4. **Gain contingencies**: **Never accrue**, only disclose if probable

5. **Range with no best estimate**: Use **MINIMUM**

6. **Warranties**: Assurance type → Accrue as contingency (ASC 450)

7. **Guarantees**: Always disclose (even if remote)

---

## Common CPA Exam Mistakes

### Mistake 1: Reasonably Possible
**Wrong**: Accruing reasonably possible loss
**Correct**: **Disclose only** (do not accrue)

### Mistake 2: Gain Contingencies
**Wrong**: Accruing probable gain
**Correct**: **Never accrue** gains (only disclose)

### Mistake 3: Range Measurement
**Wrong**: Using midpoint of range when no amount is more likely
**Correct**: Use **MINIMUM** of range

### Mistake 4: Remote Losses
**Wrong**: Disclosing remote losses
**Correct**: **No disclosure** for remote (except guarantees)

| **Reasonably Possible** | 25-75% | **Disclose only** (do not accrue) |
| **Remote** | <25% | **No action** (except guarantees - always disclose) |

## Summary

### Loss Contingencies
- **Probable + Estimable** → **ACCRUE and DISCLOSE**
- **Reasonably possible** → **DISCLOSE only**
- **Remote** → **No action** (except guarantees)

### Gain Contingencies
- **Never accrue** (conservatism)
- Disclose if probable (with caution)

### Measurement
- Use best estimate
- If range with no best estimate → Use **MINIMUM**

### Key Formulas
```
Accrue if: Probable (>75%) AND Reasonably Estimable

Range measurement: Use minimum if no amount more likely

Warranty estimate: Sales × Estimated warranty rate
```
